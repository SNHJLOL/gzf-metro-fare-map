# 广佛地铁 · 票价可达图

一张**单文件、零外部依赖**的交互式地图：选一个起点站，立刻看到「坐到任意一站要几块钱」的等票价圈，外加完整线网、热门起点与「全部车站」里程排行。

覆盖广州 + 佛山全网约 360 座车站，票价按广州/佛山地铁里程阶梯计价规则计算（含换乘绕行的真实最短乘车路径）。

## 直接看效果

- **在线版（已上线，手机/桌面通用）**：<https://gzf-metro-fare-map.app.workbuddy.host/?sharecode=KSVY7ZWEJJ>
- **源码仓库**：<https://github.com/SNHJLOL/gzf-metro-fare-map>
- **本地单文件**：打开仓库根目录的 [`广州地铁票价地图.html`](./广州地铁票价地图.html)，双击即可在浏览器里运行——无需服务器、无需联网、没有任何外部请求。

## 功能

- **等票价圈**：选起点后，地图用颜色带标出「2 元 / 3 元 / …」能到的范围，圈住的就是对应票价内所有车站。
- **线网与站名**：完整绘制所有线路，仅标注换乘站（右上可切到「自动」显示更多站名）。
- **起点任意换**：点任意站点即设为新起点；手机上轻点即可，拖动则用于平移地图。
- **热门起点 + 全部车站**：一键切到体育西路、广州南站等常用站；或在列表里按里程 / 均价排序浏览全网。
- **双指缩放 / 拖拽**（手机）：缩放锁定手指中点，不漂移。
- **计价规则**：顶栏「i」按钮弹出完整的分段计价说明。

## 适配说明

已对手机端做专项适配：纵向三段布局、面板可收起换整屏地图、按设备实测视口高度（兼容不支持 `dvh` 的老内核）、线路与等费圈线宽按缩放比换算（兼容不支持 `non-scaling-stroke` / 大坐标栅格化溢出的内核）。

## 本地构建

```bash
node build.js     # 从 src/template.html + data/ 生成 广州地铁票价地图.html 与 dist/index.html
```

## 回归测试

测试脚本需要 Playwright（桌面 Chrome）：

```bash
npm i -D playwright && npx playwright install chromium
npm test          # 依次跑 test_ui / test_ring / test_mobile
```

- `test_ui.js` — 桌面端交互与渲染
- `test_ring.js` — 等费圈几何正确性（每个站是否落在正确票价侧）
- `test_mobile.js` — 多视口手机布局与手势

## 目录结构

```
src/template.html  页面模板（内联 CSS/JS，构建时注入数据）
data/              原始与中间数据（站点、线路、行政区边界 geojson）
build*.js          数据预处理与单文件构建
*.js               源码与测试
广州地铁票价地图.html  构建产物（可直接打开的单文件）
```

## 数据来源

站点 / 线路来自公开地铁线网数据；行政区边界来自高德地图行政区查询接口。票价计算依据广佛地铁官方里程阶梯计价规则实现，仅供可视化参考，不做任何出行 / 费用决策担保。
